# Contributing

This is a personal project, so I'm not actively maintaining it or reviewing pull requests. That said, feel free to fork it and make whatever changes work for you.

If you find a bug or have an idea for an improvement, you're welcome to open an issue or submit a PR, but don't expect a response. Your best bet is to just fork the repo and build on it yourself.

Some areas that might be worth looking at if you're extending it:

- Adding more chart types or workout analytics
- Performance optimizations for large training histories
- Better handling of edge cases in the muscle attribution logic

Have fun with it.
